# V TRADE AI v5.2.1 — Quick Start

1. Deploy the folder to Render with `npm install` and `npm start`.
2. Set `MT5_BRIDGE_API_KEY` to the same secret used by the MT5 Python bridge.
3. Set `MT5_SYMBOL` to the broker symbol (for example `XAUUSD` or `XAUUSD-STDc`).
4. Keep MT5 + the bridge running. The dashboard should show `MT5 LIVE`.
5. Open XAUUSD and press `Scan Analysis`.
6. The scanner will remain WAIT/WATCH until its confirmation gate is satisfied.
7. Telegram: enter the user's own Bot Token + Chat ID in Telegram Setup, then Connect & Send Test.

Important:
- Setup Score is NOT a guaranteed probability or win rate.
- BUY/SELL is an indicative analysis state, not automatic broker order execution.
- Telegram per-user credentials are held in server memory only in this build; a Render restart requires reconnect.
- For true 24/7 alerts while the browser is closed, add a persistent encrypted database and a server-side scheduler/worker.
